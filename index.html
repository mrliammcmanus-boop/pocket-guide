How privacy and offline access work

The itinerary, photos and walking maps are encrypted together. The public site contains the unlock screen and encrypted file, not a readable copy of your plans.

Anyone with the passphrase can read the guide. Keep it separate from the link. Remembered access lets someone using this unlocked device read it too.

The download works without a connection. External Maps directions, booking pages and venue websites still need internet. Browsers can remove saved site data, so retain the PDF as a backup.
